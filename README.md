# El prompt con el que Claude hizo «Un mundo sin ruido»

Página regalo del CTA **ESTRATEGIA** (@soydiegoosorio): el prompt del video «Un mundo sin ruido», hecho con un clon de IA, y la
estrategia con la que usamos los agentes de IA en los negocios. Una página por video.

Página: https://diegodoc1111.github.io/prompt-mundo-sin-ruido/

## Fuentes verificadas
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup
- Higgsfield CLI (`npm install -g @higgsfield/cli`, `higgsfield auth login`): mismo paso de la guía
  https://diegodoc1111.github.io/clonarte-con-ia/ y el CLI que usamos para este video.
- Costo por segundo (Seedance 2.5, 480p, unos 3 créditos/s): cobros reales de la cuenta al hacer estos videos.
- El prompt técnico (`docs/prompts/mundo-prompts.txt`) es el que escribió Claude para el video, sin datos personales.
